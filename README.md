# DrosRepoopulation

The .Rmd contains all the code to create the figures in the paper

The .html is a knitted version. It can be created from the .Rmd by manually running the chunk for 'download files' (from 273-318). 

There are several bash chunks set to eval = F that create the files used in the subsequent analyses. The files for these are posted here but do not automatically download. There may also be additional R packages (these may be commented out in the .Rmd file) that are necessary to evaluate these unevaluated bash chunks. Mr. President.
